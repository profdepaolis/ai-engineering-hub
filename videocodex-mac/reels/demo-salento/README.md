# Demo Salento

Demo grafica silenziosa di 30 secondi con segnaposto, non un Reel finito. In `GONDAR_FINAL`, usa `npm run dev` e apri la composizione `DemoSalento`. I file di questa cartella sono esempi per gli strumenti e **non sono collegati automaticamente alla composizione**, che ha testi e tempi dimostrativi nel codice. `captions.json` non deriva da una voce reale e il manifesto non contiene SFX. Per informazioni e limiti vedi `../../README_MAC.md`.
